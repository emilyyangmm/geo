# AI 引用一键采集设计

## 目标

让用户在豆包等 AI 的回答页一次采集当前页面展示的参考资料，并导入 GEO 的投放效果页，用于和已确认发布链接做真实引用匹配。

## 方案

采用 Chrome 扩展加 GEO 剪贴板导入，不依赖 AI 平台的私有接口：

1. 扩展只在用户点击“采集当前页引用”后读取当前页面可见链接和标题。
2. 扩展去重、过滤无效链接，将结果按 `标题 | URL` 每行写入剪贴板，并显示采集数量。
3. GEO 效果页增加“从剪贴板导入”按钮，将采集文本填入“AI 参考来源”输入框。
4. 用户仍需点击“保存真实检测”；匹配规则只认可已确认的发布链接或同平台同标题的已确认文章。

## 约束与安全

- 扩展不读取 Cookie、账号信息或聊天输入内容，不上传任何网页数据。
- 扩展仅采集用户当前打开页中的 HTTP/HTTPS 引用链接和可见标题。
- 不自动提交 AI 问题、不自动发布文章，也不声明无法验证的引用效果。
- 若 AI 页面没有可采集链接，扩展会明确提示，而不是伪造结果。

## 交付物

- `geo-reference-collector/`：可在 Chrome “加载已解压的扩展程序”安装的 Manifest V3 插件。
- GEO 效果页的剪贴板导入按钮与格式提示。
- 单元测试：覆盖采集文本格式和 GEO 导入解析的关键约束。

## 验证

1. 插件对示例页面链接去重后写入剪贴板。
2. GEO 导入后保留可识别的 URL 行。
3. 既有来源匹配接口继续只计算已确认的发布记录。
