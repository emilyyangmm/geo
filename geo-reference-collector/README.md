# GEO AI 引用采集插件

用于把豆包、DeepSeek、Kimi、千问等 AI 回答页中当前可见的外部参考链接一次性复制到剪贴板。

## 安装

1. 打开 Chrome 地址栏，输入 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录 `geo-reference-collector`。
5. 建议在 Chrome 工具栏把“GEO AI 引用采集”固定出来。

## 使用

1. 在豆包等 AI 的回答页，展开参考资料列表。
2. 点击工具栏的“GEO AI 引用采集”，再点“采集当前页引用”。
3. 打开 GEO 的“投放效果”页面，点击“从剪贴板导入引用”。
4. 核对导入链接后，点击“保存真实检测”。

插件只读取当前页可见的外部 HTTP/HTTPS 链接及其标题，不读取 Cookie、账号信息、输入内容，也不会上传任何网页数据。
